## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (stdlib only) validates `entry.png` — JPEG magic, at most
1 MiB, dimensions at most 1024×1024 — then copies it to the output
directory. The output is byte-identical on every run.
